# نظام إدارة التقارير اليومية | مستشفى اللواء الأخضر الدولي (GLRS)
### Greenland International Hospital - Daily Reports Management System

---

نظام إلكتروني متكامل، حديث، فائق السرعة والأمان لإدارة ومتابعة واعتماد دورة التقارير اليومية لكافة الأقسام والخدمات والمناوبات في **مستشفى اللواء الأخضر الدولي** (الجمهورية اليمنية - إب).

تم بناء النظام ليعمل مباشرة بتقنية **React + Vite + TypeScript** متصلاً بقاعدة بيانات **Supabase** (Auth, PostgreSQL, Storage, Row Level Security - RLS) بدون الحاجة إلى خادم Backend مستقل، مع واجهة عربية أصيلة (RTL) بهوية وألوان شعار المستشفى المعتمد.

---

## 🌟 مميزات النظام الرئيسية

1. **دورة تقارير ذكية ومتكاملة (Report Lifecycle)**:
   - مسودة (`draft`) ⬅️ رفع للمراجعة (`submitted`) ⬅️ إعادة للتعديل مع ملاحظات (`returned`) ⬅️ اعتماد وإغلاق نهائي (`closed`).
2. **محرك الاستمارات الديناميكي (Dynamic Form Engine)**:
   - إمكانية إنشاء قوالب تقارير مخصصة لكل قسم (مثل: الصيدلية، التمريض، المختبر، المناوبة الليلية، العمليات، الـ IT) بدون تعديل كود الواجهة.
   - دعم أنواع الحقول: نصوص، نصوص متعددة الأسطر، أرقام، تواريخ، أوقات، قوائم منسدلة فردية ومتعددة، مربعات اختيار، ورفع ملفات.
3. **لوحة متابعة فورية للإدارة (Hospital Admin Dashboard)**:
   - شاشة تتبع لحظية لمعرفة الأقسام التي رفعت تقرير اليوم والتي لم ترفع بعد.
   - إحصائيات ونسب إنجاز يومية دقيقة.
   - مراجعة التقارير، إعادتها بملاحظات، أو اعتمادها وإغلاقها فوراً.
4. **أمان وحماية بيانات صارمة (PostgreSQL & RLS)**:
   - حماية الجداول على مستوى السجل بقواعد Row Level Security.
   - دوال PostgreSQL آمنة ومحمية من الـ Recursion للتحقق من الأدوار والجهات.
   - عدم تخزين أي مفاتيح حساسة (Service Role) في الفرونت إند.
5. **طباعة تقارير رسمية (Print & Export to PDF)**:
   - تنسيق طباعة معتمد بترويسة المستشفى والشعار والبيانات وخانات التوقيع والختم الإداري.
6. **وضع المعاينة الفورية (Instant Demo Mode)**:
   - محرك بيانات تفاعلي يعمل تلقائياً فور تشغيل المشروع للتعرف على كامل الشاشات بدون انتظار إعداد Supabase، وينتقل تلقائياً لقاعدة Supabase الحية فور إدخال المفاتيح في `.env`.

## 👥 الأدوار والصلاحيات (User Roles)

| الدور | الوصف | الصلاحيات الأساسية |
| :--- | :--- | :--- |
| **REPORTER** (مُعد التقرير) | مسؤولو الأقسام والخدمات | لوحة متابعة جهته، إعداد تقرير اليوم، الحفظ كمسودة، التعديل، الرفع، رفع المرفقات، وتعديل التقرير في حال إعادته. |
| **ADMIN** (إدارة المستشفى) | إدارة المتابعة والرقابة والمدراء | استعراض كافة تقارير المستشفى، كشف من رفع ومن لم يرفع، إعادة التقارير بملاحظات، اعتماد وإغلاق التقارير، والطباعة. |
| **SUPER_ADMIN** (مدير النظام) | المدير العام وإدارة الأنظمة | كافة صلاحيات Admin + إدارة المستخدمين، إدارة الجهات والأقسام، إدارة قوالب وحقول التقارير، وسجل العمليات. |

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية**: React 18, Vite, TypeScript
- **التصميم وتنسيق الأنماط**: Vanilla CSS المتطور المتوافق مع الهوية البصرية لشعار مستشفى اللواء الأخضر الدولي.
- **الأيقونات**: Lucide React
- **قاعدة البيانات والخدمات السحابية**:
  - **Supabase Auth**: المصادقة الآمنة وإدارة الجلسات.
  - **Supabase PostgreSQL**: تخزين الجداول والعلاقات والفهارس والقيود.
  - **Supabase Storage**: تخزين مرفقات ووثائق التقارير في Bucket محمي.
  - **Supabase RLS**: سياسات الأمان على مستوى السطور.

## 🚀 طريقة التثبيت والتشغيل المحلي

### 1. تثبيت الحزم (Dependencies):
```bash
npm install
```

### 2. إعداد الاتصال بـ Supabase (اختياري للتجربة، إلزامي للنشر):
1. قم بإنشاء مشروع جديد في [Supabase](https://supabase.com).
2. افتح **SQL Editor** في Supabase وقم بتشغيل ملف الهيكل:
   `supabase/migrations/001_initial_schema.sql`
3. قم بتشغيل ملف البيانات التجريبية:
   `supabase/seed.sql`
4. قم بنسخ ملف `.env.example` إلى `.env`:
   ```bash
   cp .env.example .env
   ```
5. ضع رابط مشروعك ومفتاح `anon`:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```

### 3. تشغيل خادم التطوير محلياً:
```bash
npm run dev
```

افتح المتصفح على الرابط: `http://localhost:5173`

## 📦 البناء والنشر على Vercel (Production Deployment)

### اختبار البناء للتأكد من خلوه من الأخطاء:
```bash
npm run build
```

### خطوات النشر على Vercel:
1. ارفع المشروع إلى مستودعك على GitHub أو Git.
2. ادخل إلى لوحة تحكم [Vercel](https://vercel.com) واختر **Add New Project**.
3. أضف متغيرات البيئة (`Environment Variables`):
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. اضغط **Deploy**. سيتولى ملف `vercel.json` توجيه كافة المسارات تلقائياً بدون أخطاء 404 عند تحديث الصفحة.
